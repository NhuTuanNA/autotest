# Automation Testing — Interview Starter Pack

Không học thuộc câu chữ. Mỗi câu nên trả lời bằng lời của mình và kèm ví dụ thực tế.

2. Automation có thay thế Manual không?
3. Khi nào nên automate?
4. Khi nào không nên automate?
5. Smoke, Regression, Retest khác nhau thế nào?
6. Positive/Negative testing?
7. Boundary Value Analysis?
8. Severity và Priority?

3. Response gồm gì?

## Cách luyện với AI
Prompt:
> Hãy phỏng vấn tôi vị trí Junior Automation Tester. Chỉ hỏi trong các chủ đề Manual Testing, API, JavaScript cơ bản và Playwright. Mỗi lần hỏi một câu. Sau câu trả lời, chấm theo 3 tiêu chí: đúng kiến thức, rõ ràng, có ví dụ. Sau đó đưa câu trả lời mẫu ngắn gọn.
